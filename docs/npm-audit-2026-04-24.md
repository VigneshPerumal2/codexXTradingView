# npm audit notes - 2026-04-24

Command run:

```bash
npm audit --json
```

Result: 4 moderate findings, 0 high, 0 critical.

Findings:

- `bullmq` depends on `uuid <14.0.0`, advisory `GHSA-w5hq-g745-h8pq`. npm reports the available automatic fix as `bullmq@0.0.1`, which is a breaking downgrade and should not be applied automatically.
- `uuid`, transitive through `bullmq`, has the same buffer bounds advisory. Keep BullMQ isolated to local Redis queues and revisit when BullMQ publishes a safe compatible dependency path.
- `hono` under `tradingview-mcp/node_modules` has multiple moderate cookie/static/SSG advisories. This is in the upstream MCP dependency tree, not the new paper-trading dashboard.
- `@hono/node-server` under `tradingview-mcp/node_modules` has a moderate `serveStatic` repeated-slash advisory.

Decision:

- Do not run `npm audit fix` or `npm audit fix --force` automatically.
- Keep the app local-first and do not expose TradingView CDP, Redis, dashboard, or MCP services to the network.
- Re-run audit when upgrading `tradingview-mcp`, BullMQ, or Next dependencies.
